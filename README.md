# Todo Launcher

一个用 Go + Walk 实现的原生 Windows 待办面板，主打“随叫随用、贴边收起”。

## 全局热键

- 默认：`Ctrl + 小键盘 9`
- 用于快速呼出/收起主界面

## 贴边收起

- 主界面可收起为右侧小标签
- 点击小标签或热键展开

## 失焦自动收起

- 主界面失去焦点会自动收起
- 适合保持桌面干净

## 待办清单

- 圆角卡片展示
- 支持四象限类型：紧急重要 / 紧急不重要 / 重要不紧急 / 不重要不紧急
- 每条包含截止时间

## 完成动画

- 点击右侧圆形勾选
- 事项向右滑出 + 透明度降低后消失

## 排序方式

- 重要/紧急矩阵排序
- 截止时间排序

## 标签

- 新增/详情页可填写标签（逗号分隔）
- 卡片上显示第一个标签（在倒计时后）

## 标签搜索

- 底部“标签搜索”按钮
- 输入标签后仅显示匹配事项

## 详情页（右键）

- 右键待办进入详情
- 可编辑详情内容与实时进展
- 编辑自动保存

## 推迟与删除

- 待办支持推迟截止时间
- 历史事项支持删除

## 历史事项

- 托盘右键菜单打开历史面板
- 历史事项可查看详情并删除

## 提醒

- 到期提醒
- 提前提醒：可在设置中配置分钟数

## 开机启动

- 设置中勾选
- 采用 Startup 目录 `TodoLauncher.cmd`

## 数据位置

- `%APPDATA%\todo-launcher\todos.json`

## 运行

```powershell
go run .
```

## 构建（无控制台）

```powershell
go build -ldflags "-H=windowsgui" -o todo-launcher.exe .
```

## 说明

- `rsrc.syso` 由 `todo-launcher.manifest` 生成，用于启用原生 Common Controls 与高 DPI。
